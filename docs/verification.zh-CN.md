## 边界

测试覆盖资产与材质库越界、符号链接、rig 不兼容、重复演员、片段重叠、帧范围、错误类型、未知字段、重复 JSON 键、非有限数值，以及项目/镜头/引擎/资产/材质库内容漂移。编译器保护项目、镜头、清单和资产输入，包括输出文件的别名路径。

比较器验证运动、相机和构图，不自动判断画风审美、无滑步或音频一致性。共享资产未打包的外部纹理不在文件摘要覆盖范围。

GitHub Actions 复现纯 Python、安装包、Blender、编码和发布资产检查；远端状态以仓库 Actions 页面为准。
