# 创作记录

把用户的要求写在作品 `brief.md`，保持以下信息可追溯。

| 项目 | 要记录的内容 |
| --- | --- |
| 作品目标 | 画面要表达的动作、情绪及交付用途 |
| 镜头规格 | 镜头号、秒数、帧率、帧数和画幅 |
| 关键节拍 | 动作准备、主要运动、停顿与收尾发生的帧段 |
| 保留项 | 明确不能改变的机位、角色、动作、时长或风格 |
| 可调整项 | 可以试样的色板、背景、镜头运动或效果 |
| 资产选择 | 实际清单中的包 ID、角色、舞台、Action 与画风 |
| 待制作资产 | 缺少的内容、使用它的镜头，以及当前阻塞 |
| 验收方式 | 可由 CLI 检查的规则和需要观看预览判断的效果 |

## 从请求落到执行

“做一个 5 秒远景，角色跃起，最后收住，背景有纵深”：

1. 从实际资产包中确认角色、腾跃 Action、背景及适合的机位。
2. 选择已确定或合理默认的帧率；以 `frames / fps` 对齐 5 秒。
3. 根据 Action 的实际节拍标注准备、腾跃和收尾区间，不凭描述创造不存在的动作能力。
4. 在作品内保存镜头和项目配置，固定资产，执行编译、检查及预览。
5. 记录预览能否看清动作、背景是否有纵深，以及哪些地方需要继续修改。

复用 `productions/fox-study/` 的合法字段结构，不复制示例中的角色名称、骨名和色板到通用流程。新作品更换资产时重新读取包清单和兼容信息。
